# Helldivers 2 模组

这里收录我制作和测试的《绝地潜兵 2》个人模组。每个压缩包是独立项目，具体效果以对应版本为准。

## 使用提示

为了避免卡顿，同一武器的多个改版不要同时启用。部分模组需要 Bingus Shared Loader，请以压缩包内说明为准。以下为测试感想：

没错，我不能死！我不能死！我还有强敌未收拾，还有罪孽未还清，还有错误未纠正。眼下战线未平，我若再倒下，战友们必定独木难支！超级地球的阵地将被虫群与机器人撕碎，我怎可以倒下，我不能倒下！同伴们需要我！舰队需要我！超级地球需要我！需要我，绝地潜兵！ 
所以哪怕再累，再是疲乏不堪，哪怕沉眠于墓中，哪怕是死了，脑袋都被砍下来！我啊，也绝不能倒下！我要站起来，我要——再战！三气归来！
